This repository mirrors the untgz plug-in, which was previously hosted on the [NSIS wiki](https://nsis.sourceforge.io/). Its source has been rearranged so that it builds automatically; code changes are limited to build fixes.

**Are you the author?** You're welcome to take it over: [open an issue](https://github.com/nsis-community/plugin-untgz/issues/new) and we'll transfer the repository to you.

## Installation

Download the installer or archive from the [Releases page](https://github.com/nsis-community/plugin-untgz/releases).

If you downloaded the zip archive, extract it into your NSIS folder: it adds `untgz.dll` to `Plugins/<variant>/`.
